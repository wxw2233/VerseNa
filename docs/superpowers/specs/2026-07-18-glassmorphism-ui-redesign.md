# 次元人格 — 毛玻璃柔和 UI 重设计

> 日期：2026-07-18
> 风格参考：原神 PC 端（柔和版）+ Material Glass

## 1. 概述

重写全部 UI CSS，采用毛玻璃层级系统替代硬分割线。颜色变量保留（可通过主题编辑器调节），仅改形状/框架。

## 2. 毛玻璃层级系统

| 层级 | blur | 背景透明度 | 适用范围 |
|------|------|-----------|---------|
| L1 | 12px | 0.75 | 顶栏、侧栏 |
| L2 | 8px | 0.50 | 聊天消息区、设置内容区 |
| L3 | 6px | 0.55 | 卡片（气泡、设置卡片） |
| L4 | 0 | 0.60 | 输入框、按钮 |

分隔：`box-shadow: 0 0 0 1px rgba(255,255,255,0.04)` 作为感知边框，无硬线条。

## 3. 元素形状规范

| 元素 | 层级 | 圆角 | 特殊处理 |
|------|------|------|---------|
| 顶栏 | L1 | 0 (顶部平) | 底部无分割线 |
| 侧栏 | L1 | 0 | 选中项左侧 3px 圆角指示条 |
| 聊天气泡 | L3 | 12px | 用户/Agent 同形，位置区分 |
| 输入框 | L4 | 12px | 内发光边框，聚焦变色 |
| 设置卡片 | L3 | 12px | 微阴影抬离 L2 |
| 按钮 | L4 | 10px | hover 亮度 +8% |
| 头像 | - | 50% (圆) | 无外框 |
| 滚动条 | - | - | 4px，rgba(255,255,255,0.08) |

## 4. 统一原则

- 全局圆角 12px（按钮 10px 除外）
- 无硬分割线，靠层级透明度差 + 间距留白分区
- backdrop-filter 统一 blur 值
- 颜色全部走 CSS 变量，保持可调

## 5. 实施

替换以下文件的 CSS：
- `default.css` — 全局变量和基础元素
- `App.vue` — 顶栏
- `ChatView.vue` — 聊天布局
- `ChatBubble.vue` — 气泡
- `ChatInput.vue` — 输入框
- `SessionList.vue` — 侧栏
- `SettingsView.vue` — 设置面板
