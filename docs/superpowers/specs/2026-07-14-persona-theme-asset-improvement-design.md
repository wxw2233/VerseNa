# 次元人格 — 人格/主题/素材功能完善设计

> 日期：2026-07-14
> 方案：向导式创建 + 设置页优化 + 示意图素材上传

---

## 1. 概述

当前"次元设置"页面存在三个问题：
1. 创建和编辑混在一起，用户不知道当前在做什么
2. 素材上传和主题设置脱节，不知道素材会出现在哪里
3. 可自定义的 UI 元素太少

本设计通过以下方式解决：
- **创建向导**：新建对话时走完整 4 步向导（角色→主题→素材→完成）
- **设置页优化**：角色/主题/素材三个区块清晰分隔，编辑表单内联展开
- **示意图素材上传**：用界面示意图标注每个素材位置，9 个可自定义位置
- **主题编辑增强**：从 6 个参数扩展到 3 组（颜色/字体/间距）

---

## 2. 创建向导

### 2.1 触发方式

点击会话列表的「+」按钮，弹出 4 步向导（替代当前的人格选择弹窗）。

### 2.2 步骤

**步骤 1/4：选择角色**
- 显示所有可用角色卡片
- 可选择现有角色或点「+新建」创建新角色
- 必选，无默认跳过

**步骤 2/4：选择主题**
- 显示所有可用主题卡片（颜色预览）
- 可选择现有主题或点「+导入主题包」
- 必选，无默认跳过

**步骤 3/4：上传素材（可选）**
- 显示界面示意图，标注 9 个可自定义位置
- 每个位置有「上传」按钮
- 可跳过

**步骤 4/4：完成**
- 显示选择摘要（角色名、主题名、素材数量）
- 点「开始聊天」自动创建会话并进入

### 2.3 数据流

向导完成后：
1. 调用 `personaStore.switchPersona(selectedPersona)`
2. 调用 `themeStore.applyTheme(selectedTheme)`
3. 素材已通过步骤 3 上传到 `themes/{themeId}/assets/`
4. 调用 `sessionStore.createSession()` 创建会话
5. 跳转到聊天界面

## 3. 设置页改造

### 3.1 侧边栏菜单（保持不变）

```
🎭 次元设置 | 📦 主题包 | 🤖 模型配置 | 📡 通道管理 | 🔌 插件管理 | ⚡ 技能 | 🔧 工具
```

### 3.2 "次元设置" tab 内容

分为三个区块，每个区块有明确标题和分隔线：

**区块 1：角色管理**
- 标题：`角色管理`
- 当前选中标记：`当前角色：初音ミク ✓`
- 角色卡片列表（点击切换，切换后自动标记 ✓）
- 点击卡片 → 下方展开编辑表单
- 编辑表单：名称、描述、人设 prompt、情感权重滑块、说话风格下拉
- 操作按钮：保存、重置为默认、删除（default 不可删）
- 无「新建」按钮（新建走向导）

**区块 2：主题管理**
- 标题：`主题管理`
- 当前选中标记：`当前主题：默认暗黑 ✓`
- 主题卡片列表（点击切换）
- 主题编辑器：三个标签页（颜色/字体/间距）
- 每个参数修改实时预览
- 操作按钮：重置为默认、删除（default 不可删）

**区块 3：素材装饰**
- 标题：`素材装饰`
- 界面预览示意图（标注 9 个位置）
- 9 个素材上传行，每行：编号、名称、缩略图、上传按钮、移除按钮
- 不透明度滑块（仅聊天背景）

### 3.3 "主题包" tab（保持不变）

- 主题卡片列表
- 每个主题有导出和应用按钮
- 底部有导入按钮

## 4. 素材装饰系统

### 4.1 界面示意图

用纯 CSS/HTML 模拟聊天界面布局：

```
┌──────┬─────────────────────┐
│ 侧栏 │ 聊天区              │
│      │  ┌──────────────┐  │
│ 头像 │  │ 消息气泡      │  │
│      │  └──────────────┘  │
│      │                    │
│      │  ┌──────────────┐  │
│      │  │ 输入框        │  │
│      │  └──────────────┘  │
└──────┴─────────────────────┘
```

每个可自定义位置用虚线框 + 编号标注（①②③...）。
点击标注自动滚动到对应上传行。

### 4.2 素材位定义

| 编号 | 素材 | 默认文件名 | CSS 实现 |
|------|------|-----------|---------|
| ① | 聊天背景 | bg.png | `.bg-layer { background-image }` |
| ② | 角色头像 | avatar.png | `ChatBubble <img>` |
| ③ | 头像框 | avatar-frame.png | 叠加 `<img>` |
| ④ | 用户气泡装饰 | bubble-user.png | `::after` 伪元素 |
| ⑤ | Agent 气泡装饰 | bubble-agent.png | `::after` 伪元素 |
| ⑥ | 侧栏背景 | sidebar-bg.png | `.session-panel { background-image }` |
| ⑦ | 会话分隔线 | divider.png | `.session-item { border-image }` |
| ⑧ | 输入框背景 | input-bg.png | `.input-bar { background-image }` |
| ⑨ | 发送按钮 | send-btn.png | `<button>` 图标替换 |

### 4.3 上传流程

1. 用户点击「上传」
2. 弹出文件选择器
3. 选择图片后，前端用 `new File([file], targetName)` 重命名为固定文件名
4. POST 到 `/api/themes/{themeId}/upload`
5. 后端保存到 `themes/{themeId}/assets/`
6. 前端更新缩略图 + 实时应用到聊天界面

### 4.4 不透明度

- 仅聊天背景有不透明度滑块
- 通过 `chatStore.bgOpacity` 响应式联动
- `ChatView.vue` 的 `.bg-layer` 使用 `opacity` CSS 属性

## 5. 主题编辑器增强

### 5.1 三个标签页

**颜色标签：**
- 主色调、主背景、次背景、主文字、次文字、边框色
- 用户气泡色、Agent 气泡色
- 每个颜色用 `<input type="color">` + 色值显示
- 修改后实时应用 CSS 变量

**字体标签：**
- 字体族（下拉选择：Noto Sans SC、Noto Sans JP、系统默认）
- 正文字号（px 滑块）
- 小字字号（px 滑块）
- 行高（倍数滑块）

**间距与样式标签：**
- 气泡圆角（px 滑块）
- 气泡内距（px 输入）
- 侧栏宽度（px 滑块）
- 输入框圆角（px 滑块）

### 5.2 实时预览

每个参数修改后立即更新 CSS 变量：
```javascript
document.documentElement.style.setProperty('--primary', newValue)
```

### 5.3 保存与重置

- 保存：调用 PUT `/api/themes/{id}` 更新 theme.json + variables.css
- 重置：调用默认值覆盖当前主题配置
