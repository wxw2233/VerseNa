# 次元人格 — 固定形状 + 槽位覆盖 UI 改造设计

> 日期：2026-07-17
> 关联：claude-design skill（米哈游风格参考）

## 1. 概述

移除主题编辑器的形状可调项（圆角/宽度/间距），改为固定的米哈游风格 CSS 骨架。每个 UI 区域作为"槽位"，可上传图片直接替换背景/边框。

## 2. 11 个 UI 槽位

| # | 槽位 | CSS 变量 | 素材类型 |
|---|------|---------|---------|
| 1 | 顶栏背景 | `--ui-topbar-bg` | 背景图 |
| 2 | 侧栏背景 | `--ui-sidebar-bg` | 背景图 |
| 3 | 侧栏分隔线 | `--ui-sidebar-divider` | 装饰图 |

## 3. 固定 CSS 形状（米哈游风格）

| 槽位 | 默认 CSS |
|------|---------|
| 顶栏 | 渐变底栏 + 底部微光分隔线 |
| 侧栏 | 右侧渐变光边（`border-image: linear-gradient`） |
| 分隔线 | 发光渐变线（`linear-gradient(90deg, transparent, rgba(160,130,255,0.5), transparent)`） |
| 聊天气泡 | `border-radius: 4px 14px 14px 14px` 菱形切角 + `box-shadow` 微发光 |
| 输入框 | 底部拉长圆角 + 内发光 |
| 发送按钮 | `clip-path: polygon(10% 0, 100% 0, 90% 100%, 0 100%)` 倾斜菱形 + 外发光 |
| 卡片 | 圆角 6px + 细边框 + 微内发光 |
| 头像框 | 发光外环 `box-shadow` |

## 4. 主题编辑器改造

- **删除：** 间距子标签页（气泡圆角/侧栏宽度/输入框圆角/气泡内距）
- **保留：** 颜色子标签、字体子标签
- **改造：** 素材子标签 → 11 槽位网格布局，每个槽位显示名称+预览+上传按钮

## 5. 存储结构

```json
{
  "theme": {
    "colors": { "primary": "#7c5cfc", ... },
    "fonts": { "family": "...", "sizeBase": 14, ... },
    "slots": {
      "topbar-bg": "/path/to/img.png",
      "sidebar-bg": "/path/to/img.png",
      ...
    }
  }
}
```
