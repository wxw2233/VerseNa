# 项目架构索引

VerseNa 会针对当前工具工作目录生成项目架构索引，不扫描工作目录之外的文件。

## 自动内容

- 项目类型、顶层文件与目录（包括尚未包含源码的空目录）
- 常见入口文件
- Python、JavaScript、TypeScript、Vue 等源码模块
- 类、函数、接口等符号
- 常见导入关系
- `package.json` 中的脚本
- `AGENTS.md`、`README.md` 和架构说明文件是否存在

索引摘要会在每轮任务开始时提供给 Agent。详细内容通过 `project_map` 工具查询：

- `summary`：读取短摘要
- `inspect`：读取完整索引
- `search`：按路径、符号或导入关系查询
- `refresh`：文件或目录结构变化后重新扫描

索引缓存位于 VerseNa 数据目录的 `project_maps` 下，不会自动写入用户项目，也不会污染项目的 Git 状态。通过 `file_manager` 写入、移动、删除或新建目录后，当前工作区的内存索引会失效；下次读取或显式 `refresh` 会生成新索引。
